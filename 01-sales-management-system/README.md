# Sales Management System

## Project Overview

A SQL Server based Sales Management System designed to manage customers, products, orders, payments, and sales reporting.

## Technologies

- Microsoft SQL Server
- T-SQL
- Stored Procedures
- Functions
- Views
- Triggers
- Indexes
- Query Optimization

## Project Goals

- Design a normalized relational database
- Implement business rules using T-SQL
- Develop reusable stored procedures and views
- Implement inventory and sales logic
- Optimize queries using indexes and execution plans
- Maintain data integrity and transaction consistency
